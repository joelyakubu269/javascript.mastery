# Number Checker

A simple JavaScript project that checks the properties of a number entered by the user.

## Features

-How to Run the Program

Follow these steps to run the Number Checker program on your local machine.

Prerequisites
Node.js installed on your computer.
A code editor such as Visual Studio Code.
A terminal or command prompt.
Installation and Setup
Clone this repository:
bash
git clone <repository-url>

Navigate into the project directory:
bash
cd roadmap.sh

Navigate to the Number Checker project directory (if applicable):
bash
cd numberchecker

Running the Program

Run the following command in your terminal:

bash
node numCheck.js

Expected Output

The program checks whether a number is positive, negative, zero, even, or odd.

Example output:

text
{
  positive: true,
  negative: false,
  zero: false,
  even: true,
  odd: false
}
